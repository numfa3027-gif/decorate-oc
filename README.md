# Dress-Up Game

## Project Documentation

### Overview
The Dress-Up Game is a fun and interactive game where players can dress up characters using various outfits and accessories. The game features a wide range of customization options, providing users the joy of creativity and personal expression.

### Features
- Variety of characters to choose from.
- Multiple outfits and accessories.
- Save and share your creations.

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/numfa3027-gif/decorate-oc.git
   ```
2. Navigate to the project directory:
   ```bash
   cd decorate-oc
   ```
3. Open the game using your preferred method.

### How to Play
1. Select a character.
2. Choose outfits and accessories from the panel.
3. Drag and drop items onto the character to dress them up.
4. Save your creation or take a screenshot to share with friends!
